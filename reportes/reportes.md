# Reportes
{: .no_toc }

En este apartado se visualizarán todo los reportes que el usuario tiene disponibles de acuerdo a su [Grupo]({% link administracion/grupos.md %}).

[![Reportes](../../assets/administracion/reportes/reportes_varios.png)](../..//assets/administracion/reportes/reportes_varios.png){:target="_blank"}
Imagen 1. Reportes

SIR OPM permite la descarga de reportes de dos formas diferentes

Lista de espera:

Esta opción es la óptima para la descarga de reportes ya que permite la generación de reportes complejos y con una gran cantidad de datos. Al elegir descargar un reporte con esta opción activa, el reporte se comenzara a procesar en segundo plano y se notificara en la interfaz una vez que el reporte este disponible para su descarga.
[![Reportes](../../assets/administracion/reportes/reporte_en_espera.png)](../..//assets/administracion/reportes/reporte_en_espera.png){:target="_blank"}

Inmediata:

Al descargar un reporte de manera inmediata se mostrará una alerta que indica que el reporte ya esta siendo procesado así como una pantalla de carga, la cual dejará de mostrarse una vez que el reporte sea descargado. Aún cuando esta opción esta disponible únicamente se recomienda con reportes sencillos y con cantidades pequeñas de datos ya que en caso contrario es muy posible que el reporte no pueda ser generado por la plataforma.

[![Reportes](../../assets/administracion/reportes/reporte_alerta_inmediata.png)](../..//assets/administracion/reportes/reporte_alerta_inmediata.png){:target="_blank"}


Para ingresar a los reportes dentro de la alianza se debe dar click sobre el nombre de la alianza y este deplegara todos los reportes disponibles. 

[![Reportes](../../assets/administracion/reportes/reporte_barra.png)](../..//assets/administracion/reportes/reporte_barra.png){:target="_blank"}

# Acciones

Al ingresar a un reporte se mostrarán los diferentes filtros con los que cuenta el reporte para ser descargado, estos filtros son solicitados por el usuario.

[![Reportes](../../assets/administracion/reportes/filtros_alianza.png)](../..//assets/administracion/reportes/filtros_alianza.png){:target="_blank"}

Se cuenta con el apartado para la descarga en segundo plano, esta funcionalidad bloquera los filtros hasta que conluya y sea descargado el reporte solicitado. 

[![Reportes](../../assets/administracion/reportes/generar_segundo_plano.png)](../..//assets/administracion/reportes/generar_segundo_plano.png){:target="_blank"}

El sistema enviará una notificación en la misma pantalla cuando el reporte este listo para ser abierto.
