Imagen 1. Administrador de usuarios.


## Usuarios 



### Creación de usuarios


  Para dar de alta un nuevo usuario se debe dar click en el botón [![Captura de pantalla del boton crear usuarios](../../assets/administracion/alta_usuarios/boton_alta_usuario.png)](../..//assets/administracion/alta_usuarios/boton_alta_usuario.png){:target="_blank"} el cual abrirá un modal que solicitara los siguientes datos :

#### Datos para la alta de usuarios

  - **Nombre**
    - Se coloca el nombre del usuario.
  - **Apellido**
    - Se coloca el apellido del usuario. 
  - **Email**
    - El correo electrónico del usuario.
  - **Contraseña**
    - Se coloca la contraseña inicial del usuario. 
  - **Confirmación contraseña**
    - Se repite la contraseña inicial del usuario. 
  - **Botón para indicar si es super usuario**
    - Indica si el usuario contará con todos los permisos. 
    - Esta opción permite terner acceso a todas las alianzas. 
  - **Grupos**
      - Se desplegaran todos los grupos disponibles a los que puede tener acceso el usuario. 
      - Se debera seleccionar uno o varios grupos.

  [![Captura de pantalla creación usuarios](../../assets/administracion/alta_usuarios/alta_usuario.png)](../..//assets/administracion/alta_usuarios/alta_usuario.png){:target="_blank"}

  Imagen 2. Datos para la alta de usuarios.
  


### Acciones 

Por cada usuario están disponibles las siguientes acciones al hacer click en el botón marcado en rojo.

 [![Captura de pantalla creación usuarios](../../assets/administracion/alta_usuarios/boton_opciones_usuarios.png)](../..//assets/administracion/alta_usuarios/boton_opciones_usuarios.png){:target="_blank"} 

 Imagen 3. Acciones.


 **1. Actualizar**

  El botón [![Botón actualizar datos](../../assets/administracion/alta_usuarios/boton_actualizar_usuario.png)](../..//assets/administracion/alta_usuarios/boton_actualizar_usuario.png){:target="_blank"} permite actualizar los campos que se muestran en la imagen actualización de datos.

  [![Captura de actualizar usuario](../../assets/administracion/alta_usuarios/modal_actualizar_usuario.png)](../..//assets/administracion/alta_usuarios/modal_actualizar_usuario.png){:target="_blank"}

  Imagen 4. Actualización de datos.

 **2. Eliminar**

 El botón [![Botón eliminar usuario](../../assets/administracion/alta_usuarios/boton_eliminar_usuario.png)](../..//assets/administracion/alta_usuarios/boton_eliminar_usuario.png){:target="_blank"} permite remover el acceso del usuario seleccionado en la plataforma. 

  [![Confirmación de eliminación de usuario](../../assets/administracion/alta_usuarios/eliminar_registro.png)](../..//assets/administracion/alta_usuarios/eliminar_registro.png){:target="_blank"}

  Imagen 5. Confirmación de eliminación de usuario.


 **3. Restablecer constraseña**

  El botón [![Botón restablecimiento de contraseña](../../assets/administracion/alta_usuarios/boton_lastlogin_usuario.png)](../..//assets/administracion/alta_usuarios/boton_lastlogin_usuario.png){:target="_blank"} permite iniciar el proceso de restablecimiento de contraseña mediante el cual se le solicitará al usuario la creación de una nueva contraseña para su próximo inicio de sesión. 

  [![Confirmación para el restablecimiento de contraseña](../../assets/administracion/alta_usuarios/limpiar_contra.png)](../..//assets/administracion/alta_usuarios/limpiar_contra.png){:target="_blank"}

  Imagen 6. Confirmación para el restablecimiento de la contraseña.
